# Data

`bpi2017_wallets.csv` and `reference_chains.csv` are derived from the BPI Challenge 2017
event log (see "Rebuild the files in `data/`" in the main README):

van Dongen, B. (2017). BPI Challenge 2017. Version 1. 4TU.ResearchData. Dataset.
https://doi.org/10.4121/uuid:5f3067df-f10b-45da-b98b-86ae4c7a310b
